# codigoDivertido---The-Goat
Um código feito com a única intenção de me divertir e parabenizar meu amigo pela sua entrega no trabalho

## Como compilar o código:

O seguinte exemplo será dado em GCC, mas só é necessário um compilador capaz de compilar código em C++

*Como compilar?*

### Passo 1:

Clonar o repositório utilizando git clone.
Pelo terminal, insira o seguinte comando dentro da pasta onde queira guardar o projeto:

```
git clone <URL_PROJETO>
```

### Passo 2:

Neste mesmo terminal, insira o seguinte comando:

```
g++ isTGo.cpp -o isTGo
```

Feito isso, divirta-se
